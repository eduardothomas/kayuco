# Contribuir a Kayuco

Proyecto personal de Eduardo Thomas, construido en público. Los PR son bienvenidos; no hay SLA: se revisan con el mejor esfuerzo.

- Abre un issue o una Discussion antes de un cambio grande.
- Ramas `feature/*`, `fix/*` o `docs/*`; PR a `main` con la plantilla; `bash scripts/check.sh` debe pasar.
- Firma tus commits con el **Developer Certificate of Origin** (`git commit -s`). No hay CLA.
- Licencia Apache-2.0: al contribuir aceptas que tu aporte se publique bajo ella.
- Nuevos adaptadores de agentes: solo por ACP (ADR 0002) y sin tocar credenciales (ADR 0005).
- Soporte y preguntas: GitHub Discussions, canal único.
