# Seguridad

Si encuentras una vulnerabilidad, no abras un issue público. Escribe a hola@eduardothomas.com con el detalle y, si puedes, pasos para reproducirla. Respuesta con el mejor esfuerzo, normalmente en pocos días.

Principios del proyecto: Kayuco nunca guarda ni reenvía credenciales de proveedores de IA; las llaves de API que el usuario configure viven en el Keychain del sistema y nunca salen del dispositivo ni del host.
